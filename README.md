# TEST-001 – ukázka návrhu webu (demo)

Toto je **ukázkový návrh** webu pro autoservis, vytvořený jako interní test webdesignové agentury (projekt TEST-001).
**Nejde o oficiální web klienta.** Obsah označený „k doplnění“ / „ke kontrole klientem“ je zástupný,
formulář nic neodesílá a stránka je vyřazená z indexace vyhledávačů (`noindex, nofollow`, `robots.txt: Disallow: /`).

Technologie: čisté HTML5, CSS a vanilla JS, bez build kroku. Ikony a grafika jsou vlastní SVG.
